##Lab 2: Software Development Environment setup plan


## Project Scenario
Selected: Building a Simple Website - a business website with text, images, and a contact form.
## 1. IDE Selection
Tool: Visual Studio Code (VS Code)
Why: Free, works on any OS, and has built-in support for HTML/CSS/JavaScript plus useful extensions like Live Server.
## 2. Additional Tools
- Git & GitHub - version control and storing the project online
- Live Server (VS Code extension) - preview the site live in the browser
- Google Chrome + DevTools - testing and debugging
- Figma (free) - quick layout planning before coding
## 3. Hardware Requirements
- Any modern laptop (dual-core CPU, 8GB RAM,
5-10GB free space)
- Works on Windows, macOS, or Linux - no special hardware needed for a simple website.
## 4. Collaboration / Workflow (Working Solo)
- One GitHub repo with a main branch
- Create a separate branch for each feature (e.g., homepage, contact form), test it, then merge into main
- Keep files organized in folders: /css, / js, /assets
## 5. Estimated Setup Time
- Installing VS Code + Git: ~30 minutes
- Setting up GitHub + cloning repo: ~20 minutes
- Total: about 1 hour, low complexity
## 6. Setup Checklist
1. Install VS Code
2. Install Git
3. Create a GitHub account and repository
4. Clone the repository to your computer
5. Install the Live Server extension in VS Code
6. Create basic files: index.html, style.css, script.js
7. Test the site locally using Live Server
8. Commit and push changes to GitHub regularly
## Summary
This plan uses simple, free tools (VS Code, Git, GitHub, a browser) to build a basic business website. No extra frameworks or servers are needed, keeping the setup fast and low-complexity.
